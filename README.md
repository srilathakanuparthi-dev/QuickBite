# 🍔 QuickBite - Food Delivery Web App

A simple and responsive food delivery platform UI built while learning React.js.

### ✨ Features
- 🍕 Browse Restaurants & Food Items
- 🛒 Add to Cart Functionality  
- 🔍 Search Food Items
- 📱 Fully Responsive Design

### 🛠️ Built With
- React.js, JavaScript, HTML5, CSS3
- VS Code, Git, GitHub

### 🚀 How to Run
1. git clone https://github.com/srilathakanuparthi-dev/QuickBite.git
2. cd QuickBite
3. npm install
4. npm start

### 🎯 What I Learned
- React Components, Props, useState
- Responsive Design
- Git & GitHub Workflow
